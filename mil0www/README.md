# libft

A cleaned-up Libft implementation containing the mandatory character, memory,
string, output, and linked-list functions listed in `libft.h`.

## Build

```sh
make
make clean
make fclean
make re
```

Compiler flags: `-Wall -Wextra -Werror`.

This build check confirms compilation and archive creation; it does not replace
running the official subject requirements and a comprehensive Libft tester.
